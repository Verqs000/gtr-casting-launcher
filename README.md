# GTR Casting Suite Launcher

The official launcher for **GTR casters**. It installs and updates the GTR Casting Suite for Gorilla Tag (PC VR):
Auto Ref, caster camera and overlays, replays, Player Checks, Visuals and GTR Elo.

**Download:** [Latest release](../../releases/latest) → `GTR-Installer.exe`

## You need a launcher key

The launcher is free to download, but the casting mod is only sent to people with a **GTR launcher key**
(it looks like `GTR-0123456789`). Keys are given out by GTR staff. If you're a GTR caster and don't have one, ask staff.

## How to use it

1. Run `GTR-Installer.exe` and enter your launcher key.
2. It finds Gorilla Tag (Steam or Meta PC app), installs BepInEx 5 (64-bit) if needed, and downloads the mod from GTR.
3. Press **Play**. In game, press **Tab** for the menu and **F6** for the Auto Ref.
4. To send scrims to GTR, use **GTR → Sign in to GTR** in the menu and approve the code at [gtr-org.org/plugin](https://gtr-org.org/plugin).

Open the launcher again any time to update. Windows may show a SmartScreen warning because the exe isn't code-signed:
press **More info → Run anyway**.

The source code is private. This repository only hosts releases.
